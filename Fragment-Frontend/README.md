# Fragment Frontend

A beautiful, modern frontend for the Fragment decentralized compute platform.

## Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Smooth animations
- **Lucide React** - Beautiful icons

## Blockchain Infrastructure

- **SAGA** - Smart contract execution and job orchestration
- **Filecoin** - Decentralized storage for job fragments and results
- **Hyperlane** - Cross-chain messaging and encryption

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- 🚀 Submit decentralized compute jobs
- 📊 Real-time job tracking
- 🔐 End-to-end encryption with Hyperlane
- 💾 Decentralized storage on Filecoin
- ⚡ Lightning-fast UI with React Server Components
- 🎨 Beautiful gradient designs and animations

## Configuration

Update the API endpoint in `lib/config.ts` to point to your backend server.

## Build for Production

```bash
npm run build
npm start
```
